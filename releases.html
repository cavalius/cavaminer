0.35.17 · 2026-11-10

Beta. Replaces 0.35.11: the license (version 1.1) now states the 1 % PearlHash dev fee and Cavalius as the copyright holder, and the README in the packages explains that the Windows program is not code-signed yet. Mining is unchanged.

CavaMiner mines PearlHash (Pearl) on NVIDIA GPUs and RandomX (Monero) on CPUs, both from one process, on Linux and Windows.

  • Hand-written CUDA kernels for the RTX 30, 40 and 50 series; auto-tuning, undervolting with self-checks, power sweeps.
  • Follows the electricity price (38 sources, about 40 countries), mines the cheapest hours, switches profiles on a schedule.
  • Pauses while other programs use a GPU and resumes when they are done.
  • Web interface with dashboards and statistics, two-factor logins, REST API, Prometheus, Home Assistant, a terminal menu; HiveOS package.
  • Dev fee: 1 % of the PearlHash and 1 % of the RandomX mining time.

Windows: not code-signed yet. This release's Windows program has no code signature; a signed one will follow in a future release. On Windows 11 with Smart App Control on, Windows refuses to start it ("An Application Control policy has blocked this file"); otherwise SmartScreen may warn on first start (More info → Run anyway, or unblock the zip before unpacking it). Linux is not affected.

Requirements: Linux x86-64 (glibc ≥ 2.17) or Windows 10/11 x64; NVIDIA driver ≥ 525 (RTX 50 series ≥ 575). Documentation: https://cavaminer.cavalius.net
