0.37.6 · 2026-11-15

Beta. New: tuning is one tool. A tuning run measures your GPUs and CPU while they mine and sets them for the goal you choose; it replaces the auto-tune, the power sweep and the CPU clock sweep of 0.35.

CavaMiner mines PearlHash (Pearl) on NVIDIA GPUs and RandomX (Monero) on CPUs, both from one process, on Linux and Windows.

New since 0.35.17

  • Tuning runs. One run tries what you name — kernels, memory clocks, power limits, GPU clock locks, the clock offset (undervolting), the CPU's maximum clock — each kept as it is, searched by the tuner, or with your own values, and a goal chooses among what was measured: hashrate, efficiency, balance (the most efficient setting that keeps 90 % of the hashrate), power:300 (the most hashrate at or below 300 W), rate:70 (the least power for 70 TH/s) or knee (where more power stops paying). The choice is applied and saved, saved as profiles (max, balanced, efficient, or your own names with a goal each), or the run only measures. Presets start the usual runs: --tune-preset balance | hashrate | efficiency | clocks | kernels | sweep | undervolt | full | cpu.
  • The same in every interface. A run has the same fields in the settings file ([tune]), on the command line (--tune, cavaminer ctl tune), in the API (POST /api/v1/tune), the web interface, the menu and Home Assistant. cavaminer ctl tune --plan (and the Tuning page) says what a run would do and how long it takes before it starts.
  • Kept runs. Every run is kept with all its points: any point or any goal's choice can be applied later, and profiles saved from it, without measuring again (cavaminer ctl results, the Tuning page, the menu).
  • A kernel per GPU (--kernel mma52,mma23), changed while mining, and a kernel scan (--tune-preset kernels) that measures the kernels worth trying on a card — for the cards we could not test ourselves (RTX 40, the smaller RTX 50).
  • New GPU settings, applied at once from every interface: fan speed, a temperature limit, the clock cap and the clock offset.
  • A watchdog for kernels that got stuck (a clock offset too high): the miner restarts itself with the offset lowered, and a tuning run in progress goes on after the restart. The offset search ends where the voltage is at its floor.
  • Benchmarks of the RTX 3070, 3090 and 5090 and of seven CPUs, with the method: https://cavaminer.cavalius.net/benchmarks.html

Coming from 0.35

  • The old options (--autotune, --autotune-offset, --sweep and their settings) still work and start the corresponding run; the documentation's Tuning chapter lists the old and new names. Earlier results (auto-tune runs, sweeps, the CPU clock sweep) are read into the kept runs at the first start.
  • API: /api/v1/sweep and /api/v1/cpu/sweep are gone; /api/v1/tune does all of it (POST /api/v1/tune still takes the body of 0.35).
  • Home Assistant: update the integration together with the miner (copy the package's custom_components/cavaminer again).

Also in CavaMiner

  • Hand-written CUDA kernels for the RTX 30, 40 and 50 series.
  • Follows the electricity price (38 sources, about 40 countries), mines the cheapest hours, switches profiles on a schedule.
  • Pauses while other programs use a GPU and resumes when they are done.
  • Web interface with dashboards and statistics, two-factor logins, REST API, Prometheus, Home Assistant, a terminal menu; HiveOS package.
  • Dev fee: 1 % of the PearlHash and 1 % of the RandomX mining time.

Windows: not code-signed yet. This release's Windows program has no code signature; a signed one will follow in a future release. On Windows 11 with Smart App Control on, Windows refuses to start it ("An Application Control policy has blocked this file"); otherwise SmartScreen may warn on first start (More info → Run anyway, or unblock the zip before unpacking it). Linux is not affected.

Requirements: Linux x86-64 (glibc ≥ 2.17) or Windows 10/11 x64; NVIDIA driver ≥ 525 (RTX 50 series ≥ 575). Documentation: https://cavaminer.cavalius.net

0.35.17 · 2026-11-10

Beta. Replaces 0.35.11: the license (version 1.1) now states the 1 % PearlHash dev fee and Cavalius as the copyright holder, and the README in the packages explains that the Windows program is not code-signed yet. Mining is unchanged.

CavaMiner mines PearlHash (Pearl) on NVIDIA GPUs and RandomX (Monero) on CPUs, both from one process, on Linux and Windows.

  • Hand-written CUDA kernels for the RTX 30, 40 and 50 series; auto-tuning, undervolting with self-checks, power sweeps.
  • Follows the electricity price (38 sources, about 40 countries), mines the cheapest hours, switches profiles on a schedule.
  • Pauses while other programs use a GPU and resumes when they are done.
  • Web interface with dashboards and statistics, two-factor logins, REST API, Prometheus, Home Assistant, a terminal menu; HiveOS package.
  • Dev fee: 1 % of the PearlHash and 1 % of the RandomX mining time.

Windows: not code-signed yet. This release's Windows program has no code signature; a signed one will follow in a future release. On Windows 11 with Smart App Control on, Windows refuses to start it ("An Application Control policy has blocked this file"); otherwise SmartScreen may warn on first start (More info → Run anyway, or unblock the zip before unpacking it). Linux is not affected.

Requirements: Linux x86-64 (glibc ≥ 2.17) or Windows 10/11 x64; NVIDIA driver ≥ 525 (RTX 50 series ≥ 575). Documentation: https://cavaminer.cavalius.net
